# 📱 跨设备消息传输

无需安装 App，浏览器即可实现电脑与手机之间的实时消息传输。

## 功能特点

- ✅ **无需安装** - 浏览器打开即可使用
- ✅ **跨网络** - 任何网络环境都能使用
- ✅ **实时通信** - WebSocket 实现秒级消息送达
- ✅ **文件传输** - 支持图片、文档等文件传输
- ✅ **自动重连** - 断线后自动重新连接
- ✅ **设备识别** - 自动生成唯一设备ID

## 快速开始

### 1. 本地测试

```bash
# 进入服务端目录
cd server

# 安装依赖
npm install

# 启动服务器
npm start
```

打开浏览器访问 `client/index.html`

### 2. 部署到云端

1. 注册 [Render](https://render.com) 账号
2. 将代码推送到 GitHub
3. 在 Render 创建 Web Service
4. 修改客户端服务器地址为 Render 分配的 URL

## 使用步骤

1. **电脑端**：浏览器打开页面，记住你的设备ID
2. **手机端**：浏览器打开同一个页面，记住你的设备ID
3. **互相输入对方的设备ID**
4. **开始聊天！**

## 技术栈

- 前端：HTML5 + CSS3 + JavaScript (原生)
- 后端：Node.js + WebSocket
- 部署：Render.com (免费)
